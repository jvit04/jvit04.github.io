# José Viteri — Engineering Portfolio

Sitio estático bilingüe (español/inglés) publicado con GitHub Pages.

## Estructura
- `/` Inicio en español
- `/software/` Proyectos de software y concursos
- `/robotics/` Robotics & CAD
- `/certificados/` Certificaciones
- `/about/` Acerca de y contacto
- `/en/` Versión en inglés

## Desarrollo local
Abre `index.html` en el navegador o ejecuta `python3 -m http.server 8000` desde la raíz del repositorio y visita `http://localhost:8000`.

El sitio utiliza HTML, CSS y JavaScript sin proceso de compilación. Las tipografías se cargan desde Google Fonts; el resto de estilos y scripts son locales.
